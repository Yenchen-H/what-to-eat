# what-to-eat
# 🎰 今天吃什麼？

**選擇困難救星！拉一下拉霸機，讓它幫你決定今天吃哪間。**

👉 **立即使用：https://yenchen-h.github.io/what-to-eat/**

---

## 這是什麼？

每到吃飯時間就在想「要吃什麼」？這個網頁收錄了**高雄楠梓區 64 間在地餐廳**，從便當、麵食、小吃到火鍋、異國料理都有。設定好想吃的類型和預算，拉下拉霸機，3 秒內幫你選好一間，還會告訴你現在有沒有開。

## 怎麼用？

1. **挑條件**：選想吃的類型和價位，不選就代表都可以
2. **拉拉桿**：拉下右邊的拉桿，或按「開始抽！」
3. **看結果**：拉霸機停下後，會跳出這間店的完整資訊
4. **出發**：點「撥打電話」先問有沒有位子，或點「開啟地圖」直接導航

不滿意抽到的店？按「再抽一次」就好 😉

## 特色

- 🕒 **自動判斷營業中**：依照現在時間顯示「營業中、即將打烊、已打烊、今日公休」，預設只抽有開的店，不會白跑一趟
- 🍜 **8 種類型任你挑**：便當、麵食、小吃、火鍋、合菜熱炒、早午餐、異國料理、飲料甜點
- 💰 **依預算篩選**：💲 200 元以下、💲💲 200～400 元、💲💲💲 400～1000 元、💲💲💲💲 1000 元以上
- 📋 **推薦餐點**：每間店都附上招牌菜，不怕點錯
- 📞 **一鍵撥號、📍 一鍵導航**：手機上點了就能用
- 🔊 **拉霸音效**：拉桿聲、滾輪聲、中獎音效，不想吵到別人可以按右上角靜音
- 📱 **手機、電腦都好用**：畫面會自動調整成適合的版面

## 收錄範圍

主要是高雄楠梓區，包含德賢路、德祥路、惠民路、後昌路、右昌街、藍田路、土庫路一帶。

## 小提醒

- 營業時間依 Google 上的資料整理，**國定假日或店家臨時休息可能不同**，出發前建議先打電話確認
- 部分店家只收現金或需要預訂，結果卡下方的備註都有寫
- 發現資料有誤，或想推薦好吃的店，歡迎留言告訴我！
